# مَدار — Madaar

موقع تعلّم باللعب لفريق نَهْج، يجمع رقعة من 24 خلية وبطاقات «اعرف»، «استكشف»، و«حلّل». يدعم اللعب الفردي والجماعي على جهاز واحد، والعربية والإنجليزية، والمظهر الفاتح والداكن. التنفيذ الحالي HTML/CSS/JavaScript دون إطار واجهة أو خطوة بناء.

## التشغيل المحلي

المتطلبات: Node.js لتقديم الموقع، وPython 3.12 مع pip لتشغيل خدمة الأسئلة المحلية. من جذر المشروع:

```powershell
.\Start-Madaar.ps1
```

افتح `http://127.0.0.1:5600/Main.html`. بديل التشغيل في نافذة طرفية:

```powershell
node server/server.cjs
```

يمكن استخدام Live Server في VS Code؛ إعداد المشروع يستخدم `http://127.0.0.1:5502/Main.html`. خدمة الأسئلة تسمح بمنفذي 5500 و5501 و5502 و5600 على `localhost` و`127.0.0.1`. لا تفتح HTML مباشرة عبر `file://`.

### خدمة الأسئلة المحلية

في طرفية ثانية، بعد تثبيت Python 3.12:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r server/requirements-ai.txt
.\.venv\Scripts\python.exe server/run_ai.py
```

اترك طرفية الخدمة مفتوحة أثناء اللعب. الفحص: `http://127.0.0.1:8001/api/ai/health`؛ والتوثيق: `http://127.0.0.1:8001/docs`.

`Start-Madaar.ps1` يشغّل خادم الموقع فقط. ملف `Start-Madaar-AI.ps1` المذكور في بعض الرسائل والتوثيق القديم **غير موجود في جذر هذه النسخة**، ونسخة Python القديمة موجودة خارج المشروع؛ الأوامر أعلاه لا تعتمد على ذلك المسار القديم. لا يلزم نسخ بيئة Python القديمة أو وضعها في Git.

الإعداد الحالي في `service-config.js` يتصل بخدمة الحزمة المحلية على `http://127.0.0.1:8001/api/ai` للعربية. الحزمة تسترجع محتوى جاهزًا وتقيّم التحليل بالكلمات المفتاحية؛ ليست متصلة بنموذج لغة خارجي، ومحتواها عربي فقط. بتوجيه صاحب المشروع، `englishPractice: true` يفعّل بنك `question-bank.js` التدريبي الموجود عند اختيار الإنجليزية، مع إعلان المحاكاة في الإعداد والبطاقات. هذا ليس ترجمة معتمدة للحزمة أو AI حيًا، والتقييم تجريبي. العودة إلى العربية تعيد استخدام الحزمة، ولا يتحول عطل خادمها إلى محاكاة تلقائية. يمكن تعطيل التجربة الإنجليزية بوضع `englishPractice: false`. لا يُفرض هذا الاختيار على عنوان مزود خارجي مختلف اختير صراحةً.

يمر اللعب الفردي والجماعي المحلي بصفحة `Players.html` قبل الرقعة؛ الفردي يعرض لاعبًا واحدًا لكتابة الاسم واختيار اللون، والجماعي يعرض لاعبين مع إمكانية الإضافة حتى أربعة.

بعد إعادة تشغيل الخدمة ابدأ لعبة جديدة؛ الأسئلة الجارية القديمة قد تنتهي صلاحيتها. محرك اللعبة يحتسب النقاط والحركة والأدوار والفوز، وليس خدمة المحتوى.

### المحاكاة دون خدمة خارجية

افتح `AlternativePlan.html` مباشرة للوصول إلى اختيار المزود، ثم اختر المحاكاة واحفظ. الرابط لم يعد يظهر في صفحة «كيف ألعب»، لكن أدوات المحاكاة بقيت متاحة. الاختيار صريح ولا يُستخدم كبديل تلقائي عند فشل الخدمة المحلية. المحاكاة للتجربة وليست تقييمًا دلاليًا موثوقًا.

صفحة `Login.html` الحالية تحفظ الاسم في هذا المتصفح فقط، دون بريد أو كلمة مرور أو إنشاء حساب حقيقي. توجد محولات Firebase والغرف في المشروع، لكنها لا تعني أن مسار الدخول الحالي متصل بها. وثائق التكامل القديمة قد تصف واجهات أو مسارات سابقة.

## النسخة المنشورة

نشر ملفات الواجهة وحدها على Netlify لا ينشر خدمة Python أو خادم الغرف. `127.0.0.1` في المتصفح يعني جهاز الزائر، وليس جهاز الفريق. لتشغيل المحتوى الحالي لمستخدم خارجي يلزم استضافة خدمة الحزمة، وضبط عنوان HTTPS في `service-config.js`، والسماح بعنوان الموقع المنشور في CORS. لا يوجد endpoint مستضاف مؤكد في إعداد النسخة الحالية.

الغرف والحسابات تحتاج إعداداتها وخدماتها المستقلة؛ راجع `integration/firebase/` و`server/online/.env.example`. لا تضف اعتماد Service Account أو أي مفتاح سري إلى الواجهة أو README. إضافة مفتاح نموذج وحده لا يحول الحزمة المحلية إلى AI فعلي؛ هذا يحتاج تنفيذ محول الخدمة الحقيقي. لم تُنشر تغييرات هذه المهمة.

## التحقق

```powershell
node --test tests/*.cjs
.\.venv\Scripts\python.exe -m pytest server/test_package_bridge.py
```

مشكلة معروفة سابقة: `tests/firebase-service.cjs` يبحث في مسار `madaar_web/firebase-service.js` القديم بدل الملف الموجود في الجذر. هذا فشل في مسار الاختبار ولا يثبت عطل Firebase. اختبار المتصفح البصري مطلوب للعربية والإنجليزية والمظهرين وعلى الهاتف؛ الاختبارات النصية لا تغني عنه.

### مصادر تحتاج توثيقًا من صاحب المشروع

- لم أجد إثبات مصدر أو ترخيص للملفات `images/logo_1.png`, `logo_2.png`, `falak.png`, `falak_correct.png`, `falak_explains__1_.png`, `falak_thinking.png`, `falak-bot.svg`, `card.png`. لم تُنسب للفريق بلا دليل.
- أيقونات SVG المضمنة في HTML ليس لها مصدر أو ترخيص موثق في الملفات التي فُحصت.
- الحزمة المرفقة ومحتواها داخل `backend/app/data/`، والمستندات العلمية داخل `reference/`: وجود إسناد علمي لا يثبت إذن إعادة التوزيع. يلزم توثيق المصدر وحقوق الاستخدام.
- الملفات في `screens/` مراجع تصميم محفوظة، ولم أجد لها ترخيصًا عامًا موثقًا.

لا يوجد صوت خارجي موزع؛ أصوات الواجهة تولد برمجيًا عبر Web Audio في `app-ui.js`. واجهة Next.js المرفقة ليست واجهة Madaar المستخدمة.
